# Кинотеатр

Учебный проект сайта кинотеатра.

## Этапы

- `stage-1` — шапка и описание фильма
- `stage-2` — дата, кинотеатр и время сеанса
- `stage-3` — схема зала и легенда мест
- `stage-4` — итоговая сумма, кнопка оплаты и адаптивные стили
- `stage-5` — JavaScript: выбор мест, подсчёт суммы и мобильное меню
- `main` — итоговый проект

Откройте `index.html` в браузере. Кнопка оплаты — демонстрационный элемент, платежи не выполняются.
